# по нескольку раз. Убрать перк из пула — вычеркнуть из списка; без строки perks выбора нет.
#   sharp_chain  — пила наносит +100% урона (до 2 раз)

#   thick_bark   — входящий урон −15% (до 3 раз)
#   deep_pockets — вдвое больше патронов влезает, плюс немного патронов
#   lumberjack   — деревья пилятся втрое быстрее и роняют вдвое больше
#   bark_armor   — +50 брони сразу (до 3 раз)
#   second_wind  — полное здоровье после каждой зачистки
