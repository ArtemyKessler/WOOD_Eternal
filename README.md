# WOOD

Шуточный rogue-like шутер в браузере. Огромный лес вместо коридоров, на старте только
бензопила, случайные группы врагов с растущей сложностью, новое оружие за каждую зачищенную поляну.

Работает на GPL-движке [Dwasm](https://github.com/GMH-Code/Dwasm) (PrBoom+ в WebAssembly)
с ресурсами из [Freedoom](https://freedoom.github.io). Оригинальные ресурсы id Software не используются.

## Статус

Игрок стартует с одной бензопилой. Заход на поляну запирает её рядом красных факелов
и вызывает волну случайных врагов; бюджет волны растёт с каждой зачисткой.

* **Развилки с наградами.** У каждой поляны свой тип награды: оружие (дробовик, пулемёт,
  двустволка, ракетница, плазма, BFG — от старта вглубь леса), припасы (аптечки, броня),
  тайник (рюкзак, патроны) или элитная волна (враги сильнее, зато мегасфера и два перка;
  элитные поляны для логова не обязательны). У входа на каждую тропу парит светящийся
  «призрак» награды поляны на другом конце, рядом с ним — подсказка «THIS WAY: …».
  Игрок сам решает, куда идти.
* **Перки.** После каждой зачистки игра замирает и предлагает 3 перка на выбор
  (клавиши 1–3 или стрелки и Enter): урон пилы, лечение пилой и убийствами, урон дробовиков
  и всего оружия, меньше входящего урона, рюкзак, лесоруб, броня, полное здоровье после
  поляны. Перки действуют до конца забега, часть берётся по нескольку раз.
Самая дальняя поляна — логово босса (кибердемон или паук-мастермайнд со свитой): оно заперто
факелами, пока не зачищены все остальные. Победа над боссом — конец забега: финальный экран
со статистикой (поляны, убийства, время), затем титульник.
Баланс настраивается в `wad/lumps/woodcfg.txt` без пересборки движка.

* **Деревья пилятся.** Бензопила за пару секунд валит дерево, из него выпадает немного
  патронов к оружию, которое уже есть. Какие деревья пилятся и что выпадает — `saw_*` в `woodcfg.txt`.

* **Случайный лес на каждый забег.** В `wood.wad` лежат 16 раскладок (MAP01..MAP16) по 11–14 полян
  плюс логово босса, с развилками и петлями; новая игра и смерть выбирают случайную, не совпадающую с текущей.
* **Без сохранений.** Смерть — новый забег с нуля: на экране появляется «Again?»,
  пробел или Enter начинают новый забег в новом лесу.
* **Музыка.** На тропах — спокойные треки, на каждой поляне во время боя — свой боевой.
* **Своё лесное небо, титульник и логотип** рисует `tools/make_title.py`.
* Из Freedoom в `wood.wad` попадает только то, что реально используется: 28.8 МБ → 6.9 МБ.

## Структура

| Путь | Что там |
|---|---|
| `engine/` | Исходники движка (Dwasm + наши правки, см. `engine/WOOD_PATCHES.md`). GPL-2.0. |
| `wad/lumps/` | Наши лампы, которые кладутся в `wood.wad`. `woodcfg.txt` — баланс волн и наград. |
| `tools/mapgen/gen_forest.py` | Генератор 16 случайных раскладок леса MAP01..MAP16 (поляны, логово босса, развилки, петли, деревья). |
| `tools/mapgen/nodebuild.py` | Простой BSP-нодбилдер на Python: сборка карты без внешних утилит. |
| `tools/build_iwad.py` | Собирает `wood.wad` из `freedoom2.wad`: оставляет только используемые текстуры, флэты, спрайты и звуки, добавляет нашу карту и графику. Список нужных спрайтов — `KEEP_SPRITES`. |
| `tools/make_title.py` | Рисует титульник `TITLEPIC`, логотип меню `M_DOOM`, лесное небо `RSKY1` и экран смерти «Again?» (`WAGAIN`, `WAGAINK`) в палитре игры. |
| `tools/build.sh` | Полная сборка в `dist/`. |
| `.github/workflows/pages.yml` | CI: сборка и деплой на GitHub Pages. |
| `LICENSES/` | Тексты лицензий (GPL-2.0, Freedoom BSD-3, авторы Freedoom). |

## Сборка (Linux / WSL)

Нужны: [emsdk](https://emscripten.org/docs/getting_started/downloads.html), `cmake`, `gcc`,
`libsdl2-dev`, `python3` с Pillow, шрифт DejaVu, `curl`, `unzip`.

```sh
source ~/emsdk/emsdk_env.sh
./tools/build.sh
cd dist && python3 -m http.server 8080   # открыть http://localhost:8080
```

Параметры движка передаются через query string: `index.html?-warp&1&-skill&3`
(с `-warp` раскладка фиксированная — удобно для отладки).
Управление по умолчанию: WASD — движение, стрелки — поворот, Tab — карта.

## Публикация

Каждый push в `main` собирается и выкладывается на GitHub Pages
(в настройках репозитория: Settings → Pages → Source: GitHub Actions).
Содержимое `dist/` можно также залить zip-архивом на itch.io как HTML5-игру.
